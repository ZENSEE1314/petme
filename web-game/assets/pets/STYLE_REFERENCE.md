# Pet Art Style Reference

The art direction was set by a user-supplied reference image of a fire firefly chibi creature.

## Visual checklist for every pet image

- [ ] **Animal-based** — clearly recognizable as some animal (insect, mammal, fish, etc.)
- [ ] **Chibi proportions** — oversized head, small body, stubby limbs
- [ ] **Thick black outlines** — clean digital line art
- [ ] **Saturated palette** — bright but cohesive, never washed out
- [ ] **Soft rim lighting** — outer edge subtly glows in element color
- [ ] **Magical glow** — small particles or aura suggesting the element
- [ ] **Big anime eyes** — 2-3 catch lights, expressive
- [ ] **Simple smile** or expression that fits the personality
- [ ] **Element flourishes** — flames, water, leaves, lightning incorporated naturally
- [ ] **Transparent background** (or pure white if not available)
- [ ] **Square 1:1** centered composition
- [ ] **Solid silhouette** — readable at thumbnail size

## What to AVOID

- ❌ Realistic photography
- ❌ Low-poly 3D / Pokémon-Quest pixel art (different style)
- ❌ Pure white shapes with no outline
- ❌ Adult/mature character designs
- ❌ Multiple separate sub-images in one render
- ❌ Text or watermarks
- ❌ Busy backgrounds — pet should be the only focal point

## Rarity tells through art

- **Common** — simpler design, single accent color, basic pose
- **Uncommon** — one extra accessory (crown, tail, wings)
- **Rare** — more elaborate detail, dynamic pose
- **Epic** — magical effects layered onto the design
- **Legendary** — full regalia, dramatic background lighting on the silhouette
